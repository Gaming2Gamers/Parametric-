# Gaming2Gamers Parametric 3D CAD Studios

A zero-install collection of **20 single-file, interactive WebGL / Three.js Parametric 3D CAD Studios** engineered by **Gaming2Gamers** for real-time 3D world-building, `.VRM` avatar scale-accurate environments, dungeon architecture, sci-fi infrastructure, and instant `.GLB` / `.OBJ` game-asset export directly from any modern browser.

> **Zero build tools. Zero npm install. Zero server required.** Open [`index.html`](./index.html) (or any individual `.html` studio) straight in Chrome, Edge, Firefox, or Safari—or enable **GitHub Pages** to launch every studio live online.

---

## Highlights

- **19 Bespoke Parametric CAD Studios + 1 Mechanical Reference Visualization** packed into lightweight, self-contained `.html` files (`63 KB` – `172 KB` each).
- **Direct 3D Mesh Export**: Every bespoke Gaming2Gamers CAD studio exports clean Three.js geometry to **`.GLB` (glTF Binary)** and **`.OBJ`** ready for Three.js / WebGPU, Blender, Unity, Unreal Engine, Godot, and VRChat / `.VRM` worlds.
- **`.VRM` Scale & Traversal Aware**: Walkable trains, non-clipping portcullis pockets, optic turret windows, spiral towers, chasm bridges, and checkpoint shrines built for real humanoid avatar scale.
- **Instant GitHub Pages Launcher**: Includes [`index.html`](./index.html), a dark futuristic studio hub with live search, category filters, version badges, and one-click launches for all 20 studios.

## Quick Start

### 1. Run Locally (Zero Install)
```bash
git clone https://github.com/Gaming2Gamers/Parametric-.git
cd Parametric-
```
Open **`index.html`** directly in your browser—or serve locally for clean URLs:
```bash
npx serve .
# or
python -m http.server 8080
```

### 2. Deploy Instantly with GitHub Pages
1. Open repository **Settings -> Pages**.
2. Under **Build and deployment**, select **Deploy from a branch**.
3. Choose branch **`main`** and folder **`/ (root)`**, then click **Save**.
4. Visit **`https://gaming2gamers.github.io/Parametric-/`** to browse and launch all 20 studios online.
